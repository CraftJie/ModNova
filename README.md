# ModNova

主从一体的 Modbus 调试工具：一个窗口的桌面程序，支持 **Modbus TCP**、**RTU**（串口）和
**RTU over TCP**（串口服务器 / DTU / 4G 网关透传）。

拿它可以连设备读寄存器并持续轮询、把 16 位整数按 float32 之类的真实类型解释出来、就地改写
某个寄存器、粘一帧报文逐字段拆开看，或者自己起一个从站，没有实物也能联调。

## 下载与安装

Windows 10 / 11 64 位，**解压即用，不需要安装 Python，串口支持也已内置**。

1. 打开 [Releases](https://github.com/CraftJie/ModNova/releases/latest) 下载
   `ModNova-<版本>-win-x64.zip`（约 12 MB）
2. 解压到任意目录，比如 `D:\Tools\ModNova`
3. 双击 `ModNova\ModNova.exe` 运行

双击后如果 Windows 提示「已保护你的电脑」，点 **更多信息 → 仍要运行** 即可（程序用的是开源项目
常见的自签证书）。想确认下载完整，可以对照同一页的 `SHA256SUMS.txt` 校验 zip 的 SHA256。

## 快速上手

在链路卡里选 TCP 或串口，填地址和站号，点「连接」—— 连上就开始轮询，不用再点「开始」。

## 基本用法

**读。** 选功能码 01/02/03/04、起始地址、数量，表格按拍刷新（没有单独的「读取」按钮，
改完参数下一拍就生效）；想立刻取一次按 `F5`。地址框右边的下拉决定怎么读这串字：
十进制、十六进制，或 PLC 地址（从 40001 开始，设备手册一般写这种）。工具条最右侧可在
「概览」（Modbus Poll 式网格）和「明细」（一点一行，数值 / 十六进制 / 二进制并列）之间切换。

**解释数值。** 「数据定义」里设置类型、字节序、比例系数、偏移量和单位：

- 类型：`uint16 / int16 / uint32 / int32 / float32 / uint64 / int64 / float64 / ascii`
- 字节序：`ABCD / BADC / CDAB / DCBA`
- 缩放：`显示值 = 原始值 × 比例系数 + 偏移量`（写的时候自动反算）

float32 读出天文数字、负数是乱的，基本都出在这两处：先把字节序四种试一遍，负数把类型
改成 `int16 / int32`。

**写。** 选 05/06/0F/10/16 写功能码，填值，按 `F5`，写完会自动回读确认真的写进去了。
也可以直接双击表格里的格子就地改：回车提交，`Esc` 取消。

**起一个从站。** 从站页能起 TCP 或串口从站，主站连过来就能自测，全程不需要真实设备。
默认只监听 `127.0.0.1:5020`（502 端口常被别的 Modbus 软件占用）。Modbus 协议没有鉴权，
除非在隔离网段联调，不要把监听地址改成 `0.0.0.0`。

**看报文。** 每次收发的原始帧都在日志里；从站页还能给上位机「使坏」（丢包、延迟、异常码、
坏 CRC），验证容错逻辑。

**快捷键。** `F5` 执行一次 · `Esc` 停止轮询 · `Ctrl+1 / Ctrl+2` 主站 / 从站 ·
`Ctrl+I` 读设备标识 · 右键复制整表（TSV，可直接粘进 Excel）。

## 遇到问题

- **被 SmartScreen 拦住** —— 点「更多信息 → 仍要运行」。程序未购买商业代码签名证书。
- **502 端口起不来** —— 被别的 Modbus 软件占用，或没有权限。模拟器默认用 5020，
  客户端跟着改就行。
- **串口打不开** —— 多半被其他程序占着，关掉对方再试；USB 转串口建议先在设备管理器里
  确认端口号。
- **读到的值和手册对不上** —— 先确认地址记法（手册的 40001 通常对应协议地址 0），
  再确认字节序，float32 最容易栽在这里。
- **顶栏显示「无响应」** —— 看日志里有没有 TX / RX：只有 TX 是站号或接线、串口参数的问题；
  TX、RX 都有但报 CRC 错，是波特率或干扰的问题。
